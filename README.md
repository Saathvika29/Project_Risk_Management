# Intelligent Project Risk Prediction & Management System

An ML-based decision support system that predicts project risks and provides actionable risk management insights.

## Features
- Risk Type, Impact, Probability and Response Plan Prediction
- Risk Severity Analysis
- Risk Prioritization
- Risk Interdependency Analysis using NetworkX
- Intelligent Risk Recommendations
- Interactive React Dashboard

## Machine Learning
Implemented and compared five algorithms:
- Decision Tree
- Random Forest
- Logistic Regression
- Support Vector Machine (SVM)
- XGBoost

Random Forest was selected based on model evaluation results.

## Tech Stack
- **Machine Learning:** Python, Scikit-learn, XGBoost
- **Backend:** Django REST Framework
- **Frontend:** React.js, Vite, CSS, Recharts
- **Analysis:** Pandas, NumPy, NetworkX

## Dataset
5,000 synthetic project records with 26 input features and 4 prediction targets.

## Project Status
ML models, prediction APIs and four decision-support functionalities implemented. Database integration and authentication are planned.
